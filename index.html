FintList>
C:\Projects\fintlist High-performance int list · co-developed with a classmate

A doubly linked list for primitive int stored in three parallel arrays instead of node objects, which cuts allocations and garbage-collector pressure.

~8×faster addAt/removeAt~10Melements1.63doubling ratio (vs 2.10)
  • Reuses free slots, caches the last access and starts each traversal from the head, the tail or the last accessed node, whichever is closer.
  • About 8× faster addAt/removeAt than the course's linked list at ~10M elements. Both are O(n): the gain comes from smaller constant factors, not from a complexity change.
  • Benchmarked with Monte Carlo random positions and doubling-ratio tests (mean ratio for addAt 1.63 vs 2.10).
  • Its iterative deepCopy handled lists far larger than the course list's recursive copy, which overflowed the stack.

Maritime Navigation Simulator>
C:\Projects\maritime-navigation Route planning simulator · 3-person team · Apr – Jun 2026

A discrete-time maritime traffic simulator with a Swing GUI, built test-first.

  • Dijkstra route planning on a graph that contains no obstacle-crossing edges.
  • Design patterns: Strategy (pluggable routing algorithms), State (ship life cycle), Mediator (a control tower that resolves collisions), Iterator (on-time ship departures), Command (GUI actions).
  • Collision avoidance: ship areas are circles, priority goes by trip code, and the yielding ship waits and then resumes its route.
  • The GUI reads read-only simulation snapshots, so the interface stays decoupled from the navigation logic.
